# gRPC

The gRPC MicroProfile API is an extension to Helidon MP that enables building gRPC services integrated with MicroProfile APIs.

| Topic                    | Description                                                                                                                                                                                            |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [gRPC Client](client.md) | Building Java-based gRPC clients using the Helidon MP gRPC API is very simple and removes a lot of the boilerplate code typically associated with more traditional approaches of writing gRPC clients. |
| [gRPC Server](server.md) | The gRPC MicroProfile (MP) API is an extension to [Helidon MP](../README.md) that enables building gRPC services integrated with MicroProfile APIs.                                                    |
